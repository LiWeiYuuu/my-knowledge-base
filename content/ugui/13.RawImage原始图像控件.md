# RawImage是什么
RawImage是原始图像组件
是UGUI中用于显示任何纹理图片的关健组件
它和Image的区别是 一般RawImage用于显示大图(背景图，不需要打入图集的图片，网络下载的图等等)
# RawImage参数
![[Pasted image 20261126165030.png]]
==Texture：图像纹理==
UV Rect：图像在UI矩形内的偏移和大小
位置偏移X和Y(取值0~1)
大小偏移W和H(取值0~1)
改变他们图像边缘将进行拉伸来填充UV矩形周围的空间
# 代码控制
`RawImage raw = this.GetComponent<RawImage>();`
`raw.texture = Resources.Load<Texture>("lwy");`
`raw.uvRect = new Rect(0, 0, 1, 1);`
